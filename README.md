# 포트폴리오 Q&A 챗봇

채용 담당자가 경력과 프로젝트를 궁금한 순서대로 찾아볼 수 있도록 기획한 포트폴리오 챗봇입니다. 공개 포트폴리오의 자료 검색 기능을 독립 실행 버전으로 분리했습니다.

[공개 데모에서 챗봇 사용해 보기](https://beomkyu-seo-portfolio.tallsheep5.chatgpt.site/)

## Highlights

- 군 통신망 운영, 사내 IT 경험, 인프라 모니터링 랩, AI 헬프데스크 자료를 주제별로 검색합니다.
- 질문과 검색어를 비교해 관련 설명과 출처 링크를 보여줍니다.
- 관련 자료를 찾지 못하면 답변 가능한 범위를 안내합니다.
- 공개 데모와 로컬 버전은 자료 검색 모드로 동작합니다. API 키가 필요하지 않습니다.

## Why I Built This

포트폴리오를 처음 보는 방문자는 궁금한 내용이 어느 페이지에 있는지 알기 어려울 수 있습니다. 질문에서 출발해 답변과 근거 자료에 닿는 흐름을 기획했습니다. 공개 버전은 누구나 로그인 없이 체험할 수 있도록 자료 검색 방식으로 운영하기로 했습니다. 구현과 배포에는 Codex와 ChatGPT Sites를 활용했습니다.

## 로컬 실행

Node.js 20 이상이 필요합니다. 프로젝트 폴더에서 다음 명령을 실행하고 [로컬 챗봇](http://127.0.0.1:3000/)을 엽니다.

```sh
npm start
```

**챗봇에게 물어보기**를 누른 뒤 “군에서는 어떤 일을 했어요?” 또는 “헬프데스크는 매뉴얼을 어떻게 찾아요?”라고 물어보세요.

## 코드 구성

| 파일 | 역할 |
| --- | --- |
| `public/portfolio-answers.js` | 공개 자료, 키워드 검색, 검색 결과가 없을 때의 안내 |
| `public/portfolio-chat.js` | 대화 화면, 질문 전송, 답변과 출처 표시 |
| `server.mjs` | 로컬 페이지와 `POST /api/chat` 제공 |
